# Excel 出力の仕様（`js/export/`）

> CLAUDE.md から分けた詳細仕様。CLAUDE.md には要点だけを書き、詳細はここを更新する。

## ファイルの分担（`js/export/`）

`index.html` の順に読み込む。部品は `window.SKUKIKKSExport._` で共有し、各ファイルの先頭で `var box = X.box, …` と取り出す。
公開 API（`build` `collect` `parseDocs` `wareki` `KOSHU` `loadHonbun` `honbunIsSogo`）は `main.js` で付ける。

| ファイル | 作るシート・中身 |
|---|---|
| `core.js` | 共通の部品（`style` `pageSetup` `portraitSheet` `landscapeSheet` `textLine` `box` `vline` `hline` `addTable` `addBlank` ほか）、選択内容の収集 `collect`、和暦 `wareki`、工種の一覧 `KOSHU`、管理表の列幅 `W` |
| `sogo.js` | 表紙・工事概要・組織表・電気保安体制・品質管理体制・添付シート（工種別施工計画書一覧・安全衛生管理組織・活動計画表・連絡網） |
| `kanri.js` | 管理表（章ごと）・対象工事種目・作成提出資料一覧・写真撮影項目一覧 |
| `honbun.js` | 本文シート（`addHonbun`）と `data/honbun.js` の読み込み（`loadHonbun`） |
| `hannyu.js` | 機器搬入計画書・搬入時の体制表・搬入経路ほか・ワイヤロープの選定・据付け施工要領・アンカーの施工要領 |
| `kensa.js` | 使用前自主検査の検査項目・工程表・管理台帳 |
| `shiunten.js` | 総合試運転のフローとチェックリスト（`SHIUN`）・総合試運転報告書の表（`HOKOKU`） |
| `check.js` | 品質管理チェックシート（`data/checklist.js`）・工事写真の撮影箇所（`data/satsuei.js`） |
| `seko.js` | 電気設備工事施工チェックシート（表紙・使用にあたって・章と段階ごとのシート）・申請手続一覧表・〈電事則〉別表第二（`data/sekocheck.js`） |
| `main.js` | ブック全体の組み立て（`buildNow`。シート順はここで決まる） |

- 新しいシートは内容の近いファイルに足し、末尾の `X.名前 = 名前;` で公開して `main.js` から呼ぶ
- ファイルを足したら `index.html` の `<script>`（`main.js` より前）と `sw.js` の `FILES` にも足す
- 2つ以上のファイルで使う部品は `core.js` に置く（読み込み順より後のファイルの部品は使えない）

## 出力の仕様

- シート順: 表紙 → 本文 → 工事概要 → 組織表 → 電気保安体制 → 品質管理体制 → 添付シート6枚 → 対象工事種目 → 各工事の管理表 → 作成・提出資料一覧 → 写真撮影項目一覧 → 機器搬入計画書 → 搬入時の体制表 → 搬入経路・揚重計画ほか → ワイヤロープの選定 → 据付け施工要領 → アンカーの施工要領 → 使用前自主検査の検査項目 → 総合試運転 → 総合試運転報告書の表 → チェックシート → 工事写真の撮影箇所 → 施工チェックシート（表紙・使用にあたって・各章） → 申請手続一覧表 → 電事則別表第二
- 表紙・工事概要・組織表・電気保安体制・品質管理体制は書籍の総合施工計画書作成例にならう（`docs/honsho/03_2_2_sogo_rei.md`）。各A4縦1ページ
  - 表紙: 工事名 → 書類名 → 工事監理・監理 → 押印欄 → 受注者 → 押印欄（各4人分）。工種別は「管理技術者」の ※ と注記なし（作成例 p.345）
  - 工事概要: ①〜⑭は入力値。⑮電気設備概要・⑯機械設備概要は表の枠のみ（Excel 上で記入）
  - 組織表・電気保安体制・品質管理体制: 図はセルの罫線で描く（`vline` / `hline`）。未入力の氏名は「○○ ○○」
  - 添付シート: 全体工程表／工種別施工計画書一覧／安全衛生管理組織／安全衛生活動計画表／事故時等の連絡網／総合仮設計画
  - 図や表は1つずつ独立したシートにする（利用者の指示）。全体工程表と総合仮設計画は表題だけ出力し、利用者が Excel で仕上げる。
    施工図一覧表は出力しない（施工計画書では作成しない）
  - これらのシートの見出し等の表記は、作成例ではなく作成要領（同 `03_1-2_1_sogo_yoryo.md`）側に合わせる
    （本文シートは作成例の文と見出しのまま）
  - 作成例の数値が「標仕」と違うときは「標仕」に合わせる（例: EM-UTP 4対超の曲げ半径は「製造者説明書推奨値」）
- 管理表は原本と同じ列構成（A区分〜N掲載ページ）。A4横・横幅1ページに収める・見出し行を各ページに印刷
- 表紙の書類名は1行に収まらないとき 34→26→20pt に縮める。枠なしの行（`textLine`）は折り返し行数に合わせて高さを広げる
- 行の高さは文字数から見積もって明示設定（iOS の Numbers 等でも崩れにくくするため）
- 区分(A列)・項目(B列)は縦結合。約420ptごとに結合を区切り、ページをまたいでも見出しが出るようにする
- フォントは原本に合わせ「ＭＳ Ｐゴシック」

## 電気設備工事施工チェックシート（`seko.js`）

- 章・段階（準備段階／施工段階）ごとに1シート。A4縦・横幅1ページ・見出し行を各ページに印刷。シート名は「2-1 配管工事 準備」の形
- 列は 区分｜チェックポイント｜標仕の項番号｜記録（空欄）。区分は1つの区分を最後まで縦結合する（途中で区切らない。ページをまたぐと区分名は最初のページだけに出る）。検査・立会いの印は区分名の前に「(検)」「(立)」
- 1項目を1行にする（小項目①…も同じ行。罫線で分けない）。Excel の行の高さの上限（409pt）を超える項目だけ、小項目の区切りで続きの行（「（続き）」）に分ける（配管工事の「配管図」①〜㉓）
- 項番号は1行に1つ。小項目に付く項番号は、その番号の最初の行に「①」などを付ける
- 申請手続一覧表は A4横。工事区分（大・小）は縦結合（大は縦書き）。注1〜3を表の下に書く。〈電事則〉別表第二は別シート
