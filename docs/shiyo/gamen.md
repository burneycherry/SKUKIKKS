# 画面の動作・データ構造・ダウンロード

> CLAUDE.md から分けた詳細仕様。CLAUDE.md には要点だけを書き、詳細はここを更新する。

## 画面の動作仕様（`js/app.js`）

- 初回起動時は「⑴ 一般共通事項」を全選択済みにする（どの工事にも該当するため）
- 章のチェック = 章内の全項目を一括で選択／解除。一部のみ選択時は中間状態（−）表示
- ⑵〜⑼ で章内の最初の項目をチェックしたとき、共通項目も自動で選択する
  （対象: 共通事項／機材の試験／施工の立会い及び試験／機器及び完成設備。後から外せる）
- 「細目 N」ボタンで細目一覧を開き、細目単位でチェックを外せる（初回展開時に描画）
- 検索欄は 項目名・区分・細目名 の部分一致で絞り込み、該当する章を自動で開く
- 下部バーに 工事種目数・項目数・管理項目行数 を表示。管理表を出力する設定で未選択のときは出力ボタンを無効化
- 入力やチェックを変更すると、作成済みファイルの表示は消える（古い内容の誤保存防止）
- 出力ファイル名: `書類名_工事名_作成日(yyyymmdd).xlsx`（使用不可文字は `_` に置換）
- 日付は令和表記に変換して出力（`SKUKIKKSExport.wareki`）
- ①②③は連動する: ①の「工種」を変えると、登録のある工種（`KOSHU_ITEMS`）は書類の種類にかかわらず ⑵〜⑼ をその工種の項目に選び直す
  （工種別・チェックシート・撮影箇所は書類の種類を切り替えたときも選び直す）。工種欄は施工チェックシートを出すときも表示する
- 「③出力内容」で施工チェックシートにチェックがあるときだけ、その下に工事（11章）の表示欄を出す。工事は②の選択から `refresh` のたびに
  `syncSekoChap` で決め直し、`state.sekoChap[章id] = true／false` に入れる（③のチェックは操作不可）。対応は `js/app.js` の `SEKO_MAP`:
  一般共通事項＝⑴のどれか／配管＝⑵の電線保護物類・金属管・合成樹脂管2種・金属製可とう電線管／
  配線＝⑵の電線類・ライティングダクト・金属ダクト・金属線ぴ・バスダクト・ケーブル・光ファイバ・床上／接地＝⑵の接地（2項目）／
  雷保護＝⑶の雷保護装置・雷保護設備／架空＝⑵の架空配線／地中＝⑵の地中配線／機器取付け＝⑶⑺の上記以外／受変電等＝⑷⑸⑹／
  中央監視＝⑻／医療＝⑼（'other' は共通項目 `COMMON` を除く。共通項目だけでは出力しない。⑵の外線材料はどれにも割り当てない）。
  施工チェックシートを出すのに工事が0件のときは出力ボタンを無効にし、下部バーに「施工チェックシートの工事がありません（②で工事種目を選択してください）」と出す。
  管理表を出さない書類で施工チェックシートを出すときは、下部バーに管理表の選択数ではなく「施工チェックシート n工事を出力します」と出す

## データ構造（`window.KANRI_DATA`）

```
{ source, cols, chapters: [
  { id: 1, title: "⑴　一般共通事項", name: "一般共通事項", items: [
    { id: "1-0", kubun: "区分", name: "項目", groups: [
      { id: "1-0-0", c: "標仕", d: "標準図", e: "細目", rows: [
        [要点, 管理値・管理基準, 管理方法, 承検立, 作成資料, 作成写真, 提出資料, 提出写真, 掲載ページ]
      ] } ] } ] } ] }
```

- 項目(item) = 区分＋項目名が連続する範囲。細目(group) = 標仕または細目が入る行から次まで
- 選択状態は `state.sel[細目id] = true`。項目・章のチェックは細目の集計で表示
- 原本の改ページ用の見出し繰り返しは変換時に同一項目・同一細目へ統合
- 提出欄の「〇」「○」の表記ゆれは「○」に統一

## データ構造（`window.SEKOCHECK_DATA`。施工チェックシート）

```
{ source, chapters: [
  { id: "haikan", title: "2. 電力設備、…　1) 配管工事", name: "配管工事", sheets: [
    { stage: "準備段階", kubun: [
      { name: "工程", mark: ""（"検"・"立"）, items: [ { t: "1) 項目\n　① 小項目…", ref: [[0, "2-2.1.11"], [1, "2-2.1.11"], [0, "他"]] } ] } ] } ] } ],
  （ref の先頭は t を改行で分けたときの行の番号。0 は項目の見出し行）
  shinsei: { title, heads, rows: [[工事区分(大), 工事区分(小), 名称, 提出者, 提出先, 提出時期, 摘要, 法令]], notes, beppyo: { title, kind, rows } } }
```

## ダウンロードの扱い（iOS 対応）

- 生成後に `a[download]` で保存を試み、結果カードに「ダウンロード」「共有・ファイルに保存」を表示
- iOS のホーム画面アプリでは download が効かない場合があるため、`navigator.share`（ファイル共有）を併設
- 共有はユーザー操作直後でないと失敗するため、生成と共有は別タップにしている
