## 1. 施工管理表の活用（p.13）

### (1) 施工管理表の構成

- 2.1 総則（目的、適用範囲、使用上の留意事項等）と 2.2 施工管理表 で構成
- 施工管理表は「標仕」の記載事項に従い、管理内容（項目、細目、要点等）、
  管理値・管理基準、管理方法等を表にまとめたもの
- 利用しやすくするための工夫
  1. 「標仕」の記載順序に極力合わせた
  2. (1)一般共通事項では、共通工事の次に「施工計画」の区分を追加し、
     工種別施工計画書、施工図、製作図及び計算書の項目を設けた
  3. 「標仕」第2編の配管・配線工事、架空配線工事、地中配線工事、接地工事等は、
     第6編でも第2編を引用しているので (2)配管配線工事 にとりまとめた
  4. (3)電力設備工事以降では、機材の運搬時の取扱いや施工済み部分の保護を目的として
     「製品の保存」の区分を追加した

### (2) 使用方法（留意事項）

1. 受注者の品質管理システムのうち主に施工部分が対象。本社等の行為は別扱いで現場関係事項のみ
2. 「標仕」を適用する電気設備工事が対象。それ以外は監督職員と協議のうえ調整、改変、追加
3. 「標仕」の実施事項を網羅的に記載しているので、個々の工事に応じて
   項目・細目・要点などを抽出又は必要に応じて追加して使用する
4. 原則として「標仕」記載事項のみに対応。特記仕様や図面等に特記される事項は扱っていない
5. 総合施工計画書及び工種別施工計画書の作成を通じて監督職員と協議し合意を得ておく。
   施工管理表はその際の施工計画書の作成に利用する
6. 施工管理のチェックリストとして該当事項をそのまま当てはめて用いることも、
   工事内容により変更して用いることもできる
- 「要点」「管理値・管理基準」等は原則「標仕」に基づくため、使用に当たっては「標仕」と併用する

## 2.1 総則（p.14〜18）

### (1) 目的 / (2) 適用範囲 / (3) 用語の定義（p.14）

- 目的: 「標仕」に適合する工事を実施するため、施工計画書等の作成及び施工の確認において、
  適正な施工管理を行うための受注者の自主的な工事管理に資すること
- 適用範囲: 「標仕」を適用する電気設備工事。工事の種類、建物用途、規模、構造、施工条件等により
  これにより難い場合は、監督職員の承諾する他の方法によることができる
- 用語: 「標仕」第1編 1.1.2「用語の定義」による

### (4) 施工管理の実施（p.14〜15）

工事内容を把握したうえ下記の資料等を作成し、監督職員と協議し承諾を受け、
これらと「標仕」を併用しながら施工管理表の管理内容、管理方法等に基づき施工管理を行う。

- ① 施工計画書
  1. 「標仕」第1編 1.2.2 により「総合施工計画書」及び「工種別施工計画書」を作成し監督職員に提出
  2. 総合施工計画書には、施工品質を確保するための体制や方法等を記載。作成が必要な
     工種別施工計画書を明記し、特に重要と思われる工種を監督職員と協議のうえ選定
  3. 工種別施工計画書は、工事の進捗に応じて施工に先立ち作成し提出。
     品質計画に係る部分は監督職員の承諾を受ける
  4. 内容は進捗に応じて適宜検討し、変更が生じた場合は書類を修正して提出、関係者へ周知徹底。
     品質計画に係る部分の変更は監督職員の承諾を受ける
  5. 工種別施工計画書は、当該工種に応じて施工管理表の中から適宜抽出して作成。
     特に重要と思われる工種は、必要に応じて管理内容等の追加を考慮
  6. 使用者は受注者の現場担当者を想定。現場での施工の確認にも使用できるよう作成
- ② 施工図等: 「標仕」第1編 1.2.3 による施工図、製作図等は、設計図書及び施工管理表に基づき
  照合、確認し、施工に先立ち作成して監督職員の承諾を受ける（あらかじめ承諾を受けた場合は省略可）
- ③ 機材の確認
  1. 「標仕」第1編 1.4.2「機材の品質等」により、品質及び性能の証明となる資料（試験成績書等）を
     作成し提出。第2編以降の「機材の試験」で定める試験成績書も提出。
     「JISによる」と指定された機材でJISマーク表示のあるもの、及びあらかじめ承諾を受けた場合は
     提出を省略できるので、施工計画時に省略する機材を協議しておく
  2. 「標仕」第1編 1.4.3「機材の搬入」は、搬入ごとに施工管理表に基づく資料を作成し報告。
     搬入した機材は種別ごとに検査を受ける。承諾を受けた機材は報告、検査を省略できる
- ④ 施工の確認
  1. 「標仕」第1編 1.5.2「一工程の施工の確認及び報告」: 一工程の施工完了時又は工程途中で
     指示を受けた場合に確認を行い、「提出資料」欄に示す資料で報告し検査を受ける。
     「一工程」の区切り、確認の時期や方法は決まっていないので、施工計画段階で協議しておく
  2. 「標仕」第1編 1.5.4「施工の検査に伴う試験」: 施工計画書に定めた方法で実施し、
     結果を確認して試験成績書を提出
  3. 「標仕」第1編 1.5.6「施工の立会い」: 立会いを要する施工場所（箇所）等を事前に協議して定める。
     立会う施工内容及び時期は「標仕」第2編以降の「施工の立会い」による

### (5) 施工管理表の使用（p.16〜18）

#### ① 使用上の留意事項

1. 「標仕」と併用するため「標仕」欄を設けている。施工計画書の作成順序や施工管理のしやすさを
   考慮し、(1)一般共通事項の区分欄に「施工計画」を記載
2. (2)配管配線工事には、「標仕」第2編と第6編の各配管配線工事、架空配線工事、地中配線工事、
   接地工事等を併せて記載
3. 「標仕」の特記指定事項や例外・除外規定等は原則として記載していないので「標仕」を確認する
4. 網羅的に記載しているため、工事の特性によって適宜抽出又は追加して用いる

#### ② 各欄の説明

| 欄 | 内容 |
|---|---|
| 区分 | 項目の内容を各施工段階に分類。契約図書、一般事項、工事関係図書、工事現場管理、機材、施工の管理、工事検査、完成図書、共通工事、施工計画、受入検査、製作図の確認・受入検査、製品の保存 |
| 項目 | 「標仕」の節の名称 |
| 標仕 | 「標仕」の該当項目の番号 |
| 標準図 | 第2編以降の「一覧表」の番号（（電力○○）等）。「標準図」＝「公共建築設備工事標準図（電気設備工事編）令和7年版」 |
| 細目 | 項目に記載した「標仕」の項目名称。斜体は「標仕」に記載されていない細目 |
| 要点 | 「標仕」の逐条の要点を用語（キーワード）又は語句等で簡潔に記載。斜体は「標仕」に記載されていない要点 |
| 管理値・管理基準 | 「標仕」に規定された数値等、及び「標仕」の表番号とその表題。表（規格のみのものは除く）は「2.3 管理値・管理基準に記載された表一覧」、規格類は「2.4 引用規格一覧」に記載。「標仕」に無いが施工管理上必要な法令・規格等の数値、根拠法令、文献等は斜体で記載 |
| 管理方法 | 受注者の自主管理方法等 |
| 作成資料（資料） | 受注者が作成し、監督職員に報告、提出又は承諾を受ける資料。あらかじめ承諾を受けた場合は省略できるので、提出資料のリスト作成時に協議しておく。統一基準として「公共建築工事標準書式」（国土交通省ホームページ）がある |
| 作成資料（写真） | 「標仕」第1編 1.2.4「工事の記録」による工事写真。使用機材の品質、施工状況、出来形等が明確に確認又は判定できるものとし、最初の一工程の写真は作業手順がわかるようにする。撮影する内容、時期、場所（箇所）、枚数は工種ごとに施工計画書等であらかじめ定め承諾を得ておく。手引き書:「営繕工事写真撮影要領による 工事写真撮影ガイドブック 電気設備工事編 令和5年版」（（一社）公共建築協会） |
| 提出資料（資料・写真） | 監督職員に提出する資料／工事写真に ○ を記載 |
| 掲載ページ | 管理値・管理基準に記載した表の掲載ページ |

#### ③ 凡例

- 「要点」及び「管理値・管理基準」欄
  - (1)(2)…、(ｱ)(ｲ)…、(a)(b)…、①②… は「標仕」の番号
  - 斜体文字は、「標仕」の当該項目に記載は無いが、施工管理に当たって必要な確認事項
- 「要点」欄
  - 第○編○.○.○（例: 第3編1.1.4(4)〜(6)）は「標仕」の引用箇所
  - （特記）は、「標仕」で「特記による」「特記がなければ…」等の記載がある箇所。特記に留意する
  - （例外等有）は、「標仕」で「ただし、…」「なお、…」等の例外、除外規定等が記載されていること
- 「管理値・管理基準」欄: 【表○.○.○】は「標仕」に記載されている表番号
- 「管理方法」欄: 承・検・立 は原則として次による
  - 承: 監督職員の承諾を受けるもの（試験成績書を除く）
  - 検: 監督職員の検査を受けるもの
  - 立: 監督職員の立会いを受けるもの
  - 「機材」及び「施工」で、あらかじめ監督職員の指示又は承諾を受けた場合はこれによらないことが
    できるので、施工計画段階で協議しておく
- 作成資料の「資料」欄
  - □ はチェックマーク（✓）を記入するための枠
  - （写）は、原本の写しを提出資料とするもの
