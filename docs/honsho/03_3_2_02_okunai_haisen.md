## 5. 施工要領（p.361〜369）

- 5.1 二重天井内ケーブル配線・保護管（p.361）
  - ① 保護管の敷設
    - ケーブルが壁等を貫通する場合は、PF管で保護する
  - ② ケーブルの敷設
    - ケーブルは、ケーブル支持材（○○製）を用いて、2m 以下に支持する
    - 先行配線が他設備の配管・ダクト等に接触しないように、あらかじめルートの取合いを行う
    - 点検口上部にケーブルを横断させない
  - 図「二重天井内配線方法」: ケーブル、2m以下、2m以下、保護管、つりボルト、アウトレットボックス、ころがし配線、
    照明器具、保護管配線、スイッチ等、A部・B部・C部。A部詳細図・B部詳細図・C部詳細図（ケーブル支持材、結束帯）
    - 標準図「配管類3 二重天井内配線例」（PDF p.129、電力26）と同じ図（図中の文字が一致。
      標準図には「備考 ケーブル支持材の形状は、一例を示す。」がある）
- 5.2 ケーブルラックの敷設及びケーブルラック上の配線（p.362）
  - ① ケーブルラックの敷設（ZM形）
    - 水平部の支持間隔は、2m 以下とする
    - 垂直部の支持間隔は 3m 以下とするが、配線室内は 6m 以下で各階支持とする
    - つりボルトは、ケーブルラック幅が 600mm 以下は呼び径 9mm 以上、600mm を超えるものは呼び径 12mm 以上とする
    - ケーブルラックのエキスパンション部、自在継手部は、ボンディングを行う
    - 図「天井つりケーブルラックの施工」（単位 mm）: 2,000以下、上下間隔300以上、
      「ボルトは9mm以上とする（ケーブルラック幅600mm以下ボルト9mm以上、600mm超ボルト12mm以上）」
    - 図（支持方法3例）: ラック本体直接支持（一般型）［支持金具、ケーブルラック］／
      山形鋼による支持（重量型）［振止め金具、ケーブルラック、L50×50］／ダクターによる支持（重量型）
    - 標準図に該当する図は見当たらない（ケーブルラック1〜3 は記号・形式・表示例のみ）。出典は不明
  - ② ケーブルの敷設
    - ケーブル重量により、最上部でワイヤーグリップ又はプーリングアイでのつりを考慮する
    - 垂直ケーブルラックへのケーブルの支持は、1.5m 以下の間隔で固定し、同一の子桁に集中させない
    - 水平ケーブルラックへのケーブル支持は、3m 以下の間隔で固定する
    - 図「ケーブルラック配線方法」（p.363）: ［水平敷設］結束帯等にて結束、ケーブル、3m以下、結束、ケーブルラック／
      ［垂直敷設］結束、1.5m以下、結束帯等にて結束、ケーブル、ケーブルラック
    - 図「ワイヤーグリップ詳細図［例］」: ワイヤグリップ、バインド線、保護テープ、分岐部、幹線、分岐線
    - 図「プーリングアイ詳細図［例］」: 天井埋込Uボルト（スラブ鉄筋に接続）、プーリングアイ、分岐スリーブ、
      絶縁キャップ、エポキシ樹脂、幹線
    - ワイヤーグリップ・プーリングアイの図は、標準図「配管類4 垂直幹線ケーブルの一点支持例」（PDF p.130、電力27）の
      ワイヤグリップ方式・プーリングアイ方式と部品名が一致する。ただし標準図は「スラブ鉄筋に溶接」「Uボルト」
      「インサート」等の表記で、書籍の「天井埋込Uボルト（スラブ鉄筋に接続）」とは違う。同じ図かどうかは不明

- 5.3 電線・ケーブルの接続（p.364〜366）
  - ① 電線の端子接続（電力）
    - 端子部及び圧着端子に切粉等の異物がないことを確認する
    - 端子部、ボルト、ナット、圧着端子等に油分の付着がないことを確認する
    - 接続後は、ボルト、ナット、ワッシャー等の締付け状態を確認する（斜めに入っていないか、隙間がないか等）
    - チェックリストを使用し、締付け及び締付け確認忘れを防止する
    - 規定トルクで締付け及び締付け確認マーキング（ターミナルラグで接続する場合）を行う
    - 図「締付け確認マーキング方法」（p.365）: 締付け確認マーキング、スプリングワッシャー、締付けマーキング、
      ワッシャー、ボルト、約2mm
  - ② 締付けトルク値は以下とする（p.365。単位 N・m）

| サイズ | 管理値 |
|---|---|
| M5 | 2.5（25） |
| M6 | 4.0（41） |
| M8 | 13.0（133） |
| M10 | 20.0（204） |
| M12 | 50.0（510） |

    - （注）管理値の（　）内数値の単位は kgf・cm
    - ※締付トルク値は実作業や機器の端子構造に応じた強度を考慮した上で、十分な接触圧力を確保できる締付トルクとする
  - ③ 電線の端子接続（通信・情報：圧接接続）（p.366）
    - 使用する配線の心線は、0.4〜0.9mm とする
    - 端子板への接続は、端子板の専用工具を用いる
    - 端子板の接続先に示す色に合った心線を接続する
    - 専用工具で接続の際は、心線を溝に押し切り音がするまで押し込む
    - 押し込み後は、モジュールへ心線が押し込みきれていることと心線に傷がないことを確認する
    - 図: 専用工具（○○製）／接続時の押し込み（図中に「ガチッ」「一気に押し込む」）
