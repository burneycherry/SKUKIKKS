## 記録ルール

- 利用者と読み取り結果を確認できたページだけを記録する
- 写真の湾曲・透け等で確定できない箇所は「不明」または「要確認」と明記し、`00_kakunin.md` にも載せる
- 2.3 の表は「標仕」令和7年版の表と同一（利用者確認）。写真が不明瞭な箇所は国土交通省公開の PDF
  （https://www.mlit.go.jp/gobuild/content/001888825.pdf、pdftotext でテキスト抽出可）で確認する
- 2.3 では中身が同じ表が章をまたいで再掲される。再掲分は「表○○と同じ」と書き、差分だけ記録する
- 作成例の図は、図中の文字と寸法だけを記録する。形は国土交通省「標準図」PDF を参考にする（`docs/hyojunzu/README.md` に索引）
- 箇条書きの途中に表を入れるときは、表を箇条書きの本文と同じ位置まで字下げする（字下げしないと、GitHub で表のあとの
  箇条書きがコード表示になり、階層もずれる）
- 管理表（第Ⅱ編 2.2）のデータ本体は `source/*.xlsx` → `data/kanrihyo.js` が正。ここには書かない

## 照合方法（2.3 表一覧）

- 「標仕」PDF を `pdftotext`（通常・`-layout`・`-raw`）でテキスト化し、記録した各表と機械的に突き合わせた（2026-11-12）
  - 数値: 表題が一致する表の範囲に、記録した数値がすべて存在すること
  - 文言: セル・備考・注を6文字単位に区切り、PDF のどこかに存在すること
- 確認できないもの: 罫線の区切り（共通セルの範囲）、○ の位置（表1.3.1 等は個別に確認）、数値がどのセルに入るか
- PDF と違った箇所は PDF どおりに直し、各ファイル冒頭に「PDF 照合による訂正」として残した
- 2.4 の規格名称も PDF に出てくるものは照合した。年次は PDF に無く未照合
