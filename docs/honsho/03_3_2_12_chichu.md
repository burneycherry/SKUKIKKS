## 5. 施工要領（p.476〜）

- 5.1 ハンドホール（H1、H2、HP）の据付け
  - ① 掘削、砂利地業
    - 掘削する深さと幅は、次のとおりとする

| 種類 | 深さ | 幅 |
|---|---|---|
| H1-6 | 1,000mm | 1,000mm |
| H1-9 | 1,300mm | 1,000mm |
| H2-6 | 1,000mm | 1,300mm |
| H2-9 | 1,300mm | 1,300mm |
| HP45 | 800mm | 800mm |
| HP60 | 900mm | 1,000mm |

    - 底面には、全面に100mmの砂利を均一に敷きならし、振動コンパクターで2回締めする

  - ② 据付け（p.477）
    - ブロックハンドホールは、クレーンでつり上げ、分割されているハンドホールをシーリング材で接着しながら、ずれないように設置する。
      なお、使用する移動式クレーンのつり上げ荷重に応じて、当該クレーン運転免許の保有者又は小型移動式クレーン運転技能講習修了者を
      配置する。また、つり上げ荷重が1トン以上の移動式クレーンを使用する玉掛け作業は、つり荷の重量にかかわらず、
      玉掛け技能講習修了者を配置する
    - 樹脂製ハンドホールの穴明けは、強度が低下しないよう、製造者の指定する位置、大きさを守る
    - 鉄ふたの取付け面の高さは、ハンドホールに水が浸入し難くするため、地盤仕上げ面より20〜30mm程度あげる。（歩道、車路部は除く。）
- 5.2 管路の敷設（p.477）
  - ① 掘削
    - 機械掘削による布掘りとする
    - 最大管サイズの上端が指定の埋設深さ（600mm）より5cm深く掘削する
    - 根切り深さは、やりかたに水糸を張り、約2mごとに計測する
  - ② 管の敷設
    - 根切り底の石、がれきを取り除き、根切り土の中の良質土を5cm程度の厚さで均一に敷きならす
    - 管相互は、施工性を考慮して次の離隔をとる

| 呼び径 | 離隔（左右、上下）(mm) |
|---|---|
| 50以下 | 50 |
| 50超過〜150以下 | 70 |
| 150超過 | 100 |

  - ③ 埋戻し
    - 管上端より10cm程度まで砂で埋戻し、散水する
    - 管の周りに空間がないことを目視で確認後、根切り深さの1/2まで根切り土で埋戻す
    - 埋設シートを敷設して、再度、根切り土で埋戻す
    - 埋戻しは、1層の仕上り厚さを0.3m以下とし、均一に締固める
- 5.3 地中外壁貫通部からハンドホールまでの敷設（p.478）
  - ① 地中外壁貫通部
    - アジャスト型防水鋳鉄管を使用して、次のとおり施工する
    - 図（姿図と断面図）: 短尺防水管、異物継手、水切つば、可動継手、防水鋳鉄管、地中線管路、型枠、コンクリート壁、屋内、屋外・地中
  - ② ハンドホールとの接続
    - 建物とハンドホール間は、中規模の地面の想定沈下量（0.6m以下）に対応する標準図（電力31）の FM とする
    - 図（単位 mm）: 3,000（MH・HHまでの最低距離）、防水鋳鉄管、鋼製可とう管、FEP、異種管継手、至ハンドホール等、24°、R1,500、
      沈下量＝600、≒2,100、200、2,000、200、2,400。左の図: 建物側、地中側、異種管接続材、鋼製可とう管
- 5.4 地中ケーブルの引込み柱（p.478〜479）
  - コンクリート柱（12m）の根入れは2m以上とする
  - コンクリート根かせを使用し、地表面下0.3m以上で電線路の方向と平行に溶融亜鉛めっきUボルト（径：13mm以上）で締付ける
  - ハンドホールから引込み柱の立上がりは、厚鋼電線管でケーブルを保護する
  - 地中部分の厚鋼電線管は、厚さ0.4mmの防食テープを1/2重ね2回巻付ける
  - 図（p.479。単位 mm）: 足場ボルト、ケーブル支持バンド、防水処理、ケーブル保護管、接地線、同上支持バンド、2,600以上、2,500以上、
    300以上（2か所）、コンクリート根かせ、GL、Uボルト、根入れ深さ1/6以上（15m柱以下の場合）、
    金属管（厚鋼電線管）の場合は、防食テープ巻き、接地極、50以上離す
- 5.5 ケーブルの敷設（p.479〜480）
  - 配管内の状況は、ボビンを引く方法で通線に支障がないことを確認する
  - ケーブルは、キンクを起こさないように引き入れる
  - 引込口及び引出口は、ケーブルの端末処理が不完全な場合に再処理できる余長を見込む
  - ハンドホール内に次の表示札を設置する
    - 図: 表示札（合成樹脂製、ファイバ製）（2種類）、合成樹脂製バンド、麻ひも等、ケーブル。
      表示例「EM-CE14mm²-3C　3φ3W200V」「P-305→車庫棟」
  - 建物引込み部の防水処理は次のとおり行う（p.480）
    - 図: 防水鋳鉄管（可動巾 ±20mm）、ねじソケット（可動継手）（ねじ部シール剤使用）、水切つば、ねじソケット（ねじ部シール剤使用）、
      管路口防水装置、水密コンパウンド、パッキン、地中線管路、コンクリート壁厚 L、屋外・地中、屋内
