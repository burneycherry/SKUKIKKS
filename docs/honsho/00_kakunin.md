# 確認事項・保留事項の一覧

`docs/honsho/` の記録について、後から確認が必要なこと・保留にしていること・未受領の範囲をまとめる。
各ファイルに「要確認」「不明」「未受領」「未照合」と書いたときは、必ずここにも1行追加する。
解決したら「未解決」から消し、末尾の「解決済み」に日付つきで移す。

- 番号は通し番号（K-01〜）。解決しても番号は再利用しない
- 種別: 要確認＝読み取りに自信がない／確認待ち＝利用者の確認がまだ／未照合＝他資料と突き合わせていない／
  未受領＝写真をもらっていない／保留＝判断・実装を先送りしている
