## 1. 電気設備工事の施工管理の活用（p.3）

- 本書は、受注者のチェック体制が確立され自主管理が機能していることを前提とする
- 「公共建築工事標準仕様書（電気設備工事編）令和7年版」（以下「標仕」）に規定する
  受注者の役割を明確にし、施工品質の標準化を図る目的で作成
- 構成
  - 第Ⅰ編: 本書の位置付けと活用法、品質確保、発注者の業務概要
  - 第Ⅱ編: 標仕の要点、管理値・管理基準等を「施工管理表」としてまとめたもの
  - 第Ⅲ編: これらを活用した「施工計画書の作成」

### 1.1 「本書」の位置付け（図1-1）

- 本書は標仕に基づく施工管理全般を示した**参考指針**。施工計画書の作成と施工管理の実施に活用する
- 図1-1 の関係
  - 契約図書 ＝ 工事請負契約書 ＋ 設計図書
  - 設計図書 ＝ 標仕 ＋ 質問回答書・現場説明書・特記仕様書・別冊の図面
  - 標仕 →（点線）電気設備工事監理指針 →（点線）本書。文献等 →（点線）本書
  - 本書 → 施工計画書作成（品質計画）、施工管理の実施
  - 施工計画書作成（品質計画）への入力: 設計図書、監督業務方針、工事運営方針書（受注者）、本書
  - 施工計画書作成 → 施工管理の実施（施工図・製作図のチェック、現場施工のチェック）
    → 工事目的物の品質確保・向上

## 1.2 電気設備工事の流れと「本書」の活用

### (1) 工事の流れ（図1-2、p.4）

監督職員（発注者）・受注者・製造者の3列で、工程を「施工計画」「施工・施工管理」に分けて示す。
凡例: 細矢印＝作業の流れ、太矢印＝承諾・検査等のアクション、網掛け＝活用できる本書の項目。

### (2) 用語等（p.5〜6）

**① 監督職員**
- 工事請負契約書による発注者の権限を行使し、発注者組織の窓口となる
- 工事監理業務を外部委託した場合は委託業務の調査職員を兼務
- 会計法（昭和22年3月31日 法律第35号）に基づく予算執行職員として、契約図書に基づく
  履行の確認（指示、承諾、協議、立会、検査、調整）・記録、国の施策の実施における指導等を行う
- 総合評価落札方式の評価に反映された技術提案の履行状況も確認する
- 業務内容を受注者に示すため監督業務方針を作成・周知する。主な項目の例:
  1. 監督業務方針
     - 国の発注工事の原則
     - 工事監理体制、担当者の役割分担
     - 提出書類の内容と手続き（書類様式、処理方法）
     - 設計変更の内容と手続き（内容、協議、契約変更前の処理方法等）
     - 工事運営方針書、総合施工計画書、工事安全計画書への要望
     - 諸会議種別と運営方法（総合定例会議、週間工程会議）
     - 諸行事及び諸検査の予定等
  2. 工事監理方針
     - 施工計画書（監督業務と工事監理業務との関係）
     - 施策による管理項目の監理方法（重点管理項目の監督、総合評価に反映された技術提案の監理方法）
     - 一般管理項目の監理方法（監督・工事監理の方法）
     - 完成検査、技術検査、官公署検査（検査方法、対応方法）

**② 受注者**
- 現場代理人及び監理技術者又は主任技術者（建設業法の規定による）を配置し、現場を運営する
- 発注者の「要求品質」を理解して適正な施工管理を実施する
- 受注者としての工事運営方針を定め、監督職員及び工事関係者に示す（総合施工計画書に記載する場合が多い）

**③ 総合施工計画書**
- 工事運営方針を踏まえ、設計図書及び施工条件に基づき受注者等が立案する
- 着工から完成までの全体計画として、手順、体制、工法、総合仮設計画等を取りまとめ、
  関係者が共通の認識を持つことを目的とする
- 工種別施工計画書の作成概要、分類、重点管理項目等に加え、総合評価落札方式の評価に
  反映された技術提案の実施方法も記述する（第Ⅲ編 2.1「総合施工計画書作成要領」参照）

**④ 工種別施工計画書（施工要領書を含む）**
- 総合施工計画書に基づき、各工種の工事をどのように進めるかを定めた計画
- 監督職員と受注者の合意に基づくもの（合意の品質）となるため、
  **工種別施工計画書の中の「品質計画」は監督職員の承諾が必要**
- 作成に当たっては、**第Ⅱ編 2.「施工管理表」から必要事項を取り入れて作成することもできる**
  （第Ⅲ編 3.1「工種別施工計画書作成要領」参照）

## 2. 電気設備工事の品質確保（p.6〜7）

**(1) 公共建築工事の特性**
1. 公的資金を財源に公的機関が発注するため、公正性・透明性と生産過程での確実性が求められる
2. 不特定多数が利用するため利便性、耐震性・防災性などの安全性、長期耐久性が求められる
3. 地球環境の保全、省資源・省エネルギー、建設副産物対策等で先導的役割が期待される

**(2) 電気設備工事における品質確保**
- 発注者は設計図書（質問回答書、現場説明書、特記仕様書、別冊の図面、標準仕様書）で要求品質を伝える
- 本書は、設計図書のうち標仕に示される「要求品質」を取りまとめたもの
- 受注者は、要求品質を達成するため、使用機材、性能、施工品質、施工管理の方法及び体制を
  施工計画の中で取りまとめ、施工段階で実行する
- 監督職員は、施工計画書のうち「品質計画」を承諾することで「合意の品質」を確定し、
  施工段階の要所で品質と受注者の施工管理の状態を確認する

## 3. 国等の監督・検査業務の概要（p.7〜10）

### 3.1 監督業務の概要

- 監督職員の体制（工事請負契約書第9条3項）は監督業務方針に示される
  （国土交通省大臣官房官庁営繕部の例）
- 監督体制 ＝ 総括監督員・主任監督員・監督員
  - 総括監督員: 重要な指示・承諾・協議の処理、工程等の調整で重要なものの処理、
    内容変更・一時中止等の措置を発注者（契約担当官等）に報告
  - 主任監督員: 指示・承諾・協議（重要なもの及び軽微なものを除く）の処理、詳細図等の作成・交付、
    工程の管理、立会い、検査、材料の試験・検査で重要なものの処理
  - 監督員: 軽微な指示・承諾・協議の処理、工程管理、立会い、検査、材料の試験・検査
    （重要なものを除く）
- 図1-3 監督体制例: 発注者（支出負担行為担当官等）が監督職員を任命。総括監督員の下に、
  建築工事／電気設備工事／機械設備工事・エレベーター設備工事ごとに主任監督員・監督員を置く
  - 注: 本官契約の場合は支出負担行為担当官（○○地方整備局長）、
    分任官契約の場合は分任支出負担行為担当官（○○営繕事務所長）

### 3.2 工事監理業務の概要

1. 工事監理は建築基準法及び建築士法で有資格者の建築士が実施すると定められている。
   多くの場合、第三者工事監理方式により外部に業務委託される
2. 外部委託する場合の根拠
   - 建築工事監理業務委託共通仕様書（平成13年2月15日 国営整第6号、
     最終改定 令和6年3月26日 国営整第214号）
   - 建築工事監理業務委託契約書（平成13年2月15日 国官地第3-2号、
     最終改定 令和4年3月22日 国会公契第8号、国北予第26号）
3. 国土交通省の営繕工事では、工事監理業務委託と設計意図伝達業務委託（設計業務受注者に委託）
   を分離して実施。第三者工事監理方式とは、工事監理業務を当該設計業務受託者以外に委託する方式
4. 役割と責任の例は図1-4（監督職員が工事監理業務の調査職員を兼務した場合の例）
   - 登場者: 工事の監督職員・工事監理業務の調査職員（建築主、会計法（地方自治法）上の監督業務）、
     設計意図伝達業務の調査職員、工事監理業務の受託者（代表となる工事監理者A、工事監理者B〜D）、
     設計意図伝達業務の受注者、工事施工者
   - 線種: 二重線＝受発注者間の契約上の行為、細破線＝建築士法上の設計業務、
     太破線＝業務遂行上の行為、実線＝建築士法上の工事監理業務
   - Ⓐ 工事と設計図書との照合及び確認を全て終えた後、工事監理報告書等を建築主に提出
   - Ⓑ 工事施工者の工事が設計図書に適合しているかを、設計図書に定めのある方法、目視、抽出、
     品質管理記録の確認等、合理的方法により確認
5. 監督業務と工事監理業務の業務分担は「監督業務方針」の中で受注者に通知される

### 3.3 工事検査業務の概要

- 公共工事の検査は次の2つに分類される
  - **工事検査**: 「会計法」に基づく給付（契約内容）の完了の確認
  - **技術検査**: 公共工事品確法による「品確法の基本方針」及び入札契約適正化法による
    「入契法適正化指針」に基づき、適正かつ能率的な施工の確保、技術水準の向上等を目的とする
- 国の工事では、監督職員と検査職員の兼職は、特別に必要がある場合を除き禁止
- 概要（国土交通省大臣官房官庁営繕部の例）
  1. 工事検査 ＝ 完成検査（引渡しの最終段階）、既済部分検査（部分払いの請求時）、
     完済部分検査（指定部分の完成時）
  2. 上記1の要件を満たす場合、受注者は監督職員を通して発注者に完成又は請求を通知する
  3. 監督職員は、標仕 第1編 第1章 第6節 1.6.1（工事検査）の要件が満たされていることを確認し、
     工事検査の申請をする
  4. 技術検査は、標仕 第1編 第1章 第6節 1.6.2（技術検査）により、上記1の時点、
     工事施工途中（中間技術検査）、発注者が特に必要と認めたときに、発注者が受注者に通知して実施
