## 2. 総合試運転（p.519）

- 2.1 試験内容
  - 施工の最終試験として、各設備機器が設計図書で規定する停復電時及び火災時の連動動作等について、総合的なシステム間の確認を行う。
- 2.2 試験項目
  - 1) 総合試運転1（停電→復電）（5.1）: ①停電試験1 → ②復電試験1
  - 2) 総合試運転2（火災発生→停電→鎮火→復電）（5.2）: ①火災発生試験2 → ②停電試験2 → ③火災鎮火試験2 → ④復電試験2
- 2.3 試験時期
  - 週間工程表による。週間工程表は、定例打合せ会議で提出する。
- 2.4 試験機材搬入日
  - 週間工程表による。

## 3. 総合試運転実施体制（p.520）

- ① 総合試運転実施体制表。図「総合試運転実施体制表」（形は記録しない）
  - 右上: 電気主任技術者／○○地方整備局／○○○○。その下に 工事担当技術者（監督職員）: 統括・電気・建築・機械（各 ○○○○）
  - 中央（上から）: 電気保安技術者／○○○○電気工事株式会社／○○○○、品質管理責任者／同社／○○○○、代務者（現場代理人）｜○○○○
    → 試験責任者（監理技術者）／同社／○○○○ → 試験指揮者／同社／○○○○
  - 右（試験責任者と試験指揮者の間から分かれる）: 安全管理責任者／○○○○電気工事株式会社／○○○○
  - 試験指揮者の下（各枠は 名称／○○会社／担当：○○○○）
    - 上の段: 太陽光発電装置、受変電装置、自家発電装置、火災報知装置（連動制御器）、防火戸・防火シャッタ
    - 中の段: 監視制御装置、非常用照明装置、エレベータ、屋内消火栓設備、防煙ダンパー
    - 下の段: 関連装置工事（エレベータの下）、空調関連機器（防煙ダンパーの下）
- ② 総合試運転実施要領
  - 試験責任者（品質管理責任者）は、総合試運転を円滑に行うために各試験担当者に指示命令を行う。
  - 安全管理責任者は、感電・火災・事故を防ぐための安全指示を行う。停電時にエレベータ内が無人になるように対策を施す。
  - 試験指揮者は、試験係員に試験作業の指示を行う。また、試験の記録を行う。
  - 試験係員は、試験指揮者の指示に従い試験を行う。

  - 総合試運転を円滑に行うための指揮命令及び連絡系統は、①総合試運転実施体制表のとおり配置する。
    連絡手段（放送設備、無線機、携帯電話等）を明確にする。（p.521）
  - 総合試運転の実施に際し、事前に一般送配電事業者と協議を行い、試運転内容について了解を得る。
    警備保障や設備メンテナンス業者が契約している場合も同様に確認を行う。
  - ※受注者が作成しているチェックシートを添付する。

## 4. 総合試運転報告書の作成及び確認（p.521）

- 4.1 作成体制: 作成責任者 受注者の品質管理責任者 ○○ ○○／作成者 各担当の主任技術者 ○○ ○○（○○電気工事㈱）
- 4.2 作成及び確認
  - 現地の試験結果は、各工事担当の主任技術者が作成する。
  - 監理技術者は、各試験結果を総合試運転報告書として取りまとめるとともに内容を確認する。
  - 総合試運転報告書は、受注者の品質管理責任者の確認を受け、疑問がある場合は、現地で再試験する。
  - 受注者の品質管理責任者の確認後、総合試運転報告書を監督職員へ提出する。
  - ※受注者が作成している動作確認シート等がある場合は、それにより記載する。なお、低圧UV停電検出時の試験については除いている。

## 5. 総合試運転（p.521〜）

- 5.1 総合試運転1（停電→復電）
  - 商用電源が停電（①停電試験1）し、その後復電（②復電試験1）した場合に、受変電装置、自家発電装置、太陽光発電装置、
    エレベータ等の電源供給が、設計図書の条件どおりであることを確認する。
  - ① 停電試験1（p.522）。フロー図

    - 高圧UV停電検出 から3つに分かれる: 高圧交流遮断器 開／自家発電装置（破線の枠: エンジン始動 → 電圧確立 → 発電機 電磁接触器 閉）／
      太陽光発電装置 停止確認
    - 自家発電装置の枠 → 双投電磁接触器 発電機側に切替 → 発電機負荷（照明、非常用照明、コンセント、直流電源装置、通信連絡用機器、
      情報処理装置、空調関連機器、給水・排水ポンプ、入退室管理装置、火災報知受信機・連動制御器、監視制御装置等）の電源供給確認
    - 別の流れ: 低圧停電検出 → 非常用照明 点灯確認／低圧停電検出 → エレベータ停電時管制
    - チェックリスト（p.523。様式は品質管理チェックシートと同じ）

      **【停電試験1-1】：停電時の電源状態の確認**（項目: 総合試運転1（停電→復電））

- 5.2 総合試運転2（火災発生→停電→鎮火→復電）（p.525）
  - 火災が発生（①火災発生試験2）したところに商用電源が停電（②停電試験2）した。その後、火災が鎮火（③火災鎮火試験2）し、
    復電（④復電試験2）した場合に、受変電装置、自家発電装置、太陽光発電装置、エレベータ、防災機器等の電源供給が、
    設計図書の条件どおりであることを確認する。
  - ① 火災発生試験2。フロー図
    - 各設備通常状態 → 火災発生（網掛け。「火災報知感知器を加熱試験器又は加煙試験器により作動させる」）→ 火災発報（受信機）
    - 火災発報（受信機）から3つ: 空調関連（空調機、給気・排気ファン等）の停止確認及び燃焼機器、油ポンプの停止確認、
      入退室管理装置のパニックオープン確認／連動制御器（自動閉鎖設備）→ 防煙ダンパー 動作確認／エレベータ火災時管制
    - 別の流れ: 火災発報（煙感知器）→ 連動制御器（自動閉鎖設備）→ 防火戸、防火シャッタ 動作確認／
      火災確認（発信機操作）→ 屋内消火栓設備 起動確認

      **【火災発生試験2】：火災信号による防火機器等の状態の確認**（項目: 総合試運転2（火災発生→停電→鎮火→復電）。管理基準は全行「設計図書」）
