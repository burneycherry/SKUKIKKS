## 5. 施工要領（照明器具の取付け方法）（p.394〜397）

- 5.1 照明器具（埋込形）の取付け
  - 照明器具は、スラブその他構造体等よりつりボルト等で支持する。なお、ダウンライト器具は 5.2 による
  - 照明器具の取付け位置は、天井伏図及び総合図で検討し、施工図に記載する
  - 図「埋込形照明器具の取付け1」: インサート、つりボルト 呼び径9mm以上、アウトレットボックス（ブランクカバー付）、
    EM-EEFケーブル（2か所）、止具（接続点に近い箇所で支持）、照明器具
  - 天井内にダクト等がある場合の支持は、次による
  - 図「埋込形照明器具の取付け2」: インサート、照明器具用つりボルト、天井用つりボルト、ダクト等、支持材、器具、
    野縁受け、天井下地ボード、天井仕上ボード

- 5.2 照明器具（ダウンライト）の取付け（p.395）
  - ダウンライト器具で 3kg を超えるものは、スラブその他構造体等よりつりボルト等で支持する
  - ダウンライト器具で 3kg 以下は、金具又はばね構造等で脱落が防止できるものとする
  - 図「ダウンライト器具の取付け」
    - 「器具が3kgを超える場合」: つりボルト（呼び径9mm以上）
    - 「器具が3kg以下の場合」: 器具取付けばね*1（ばね構造による場合）、器具取付け金具*1（金具による場合）、
      LED制御装置*2、器具取付け金物*1（LED制御装置を併置させた器具の場合）
    - 注 *1 脱落防止を兼ねる。
    - 注 *2 LED制御装置の荷重が、器具取付け金物にかからない構造の場合、LED制御装置の質量は除く。
- 5.3 照明器具（露出形）の取付け（p.396）
  - 照明器具は、スラブその他構造体等よりボルト等で支持する（5.1 は「つりボルト等」。ここは「ボルト等」）
  - 照明器具の取付け位置は、天井伏図及び総合図で検討し、施工図に記載する
  - 図「照明器具（露出形）の取付け1」: コンクリートボックス、インサート、「スラブへの取付け」
  - 図「照明器具（露出形）の取付け2」: インサート、つりボルト 呼び径9mm以上、止具、EM-EEFケーブル、照明器具
- 5.4 2種金属線ぴ及び照明器具の取付け（p.396〜397）
  - 2種金属線ぴは、スラブその他構造体等よりつりボルト等で取付け、支持間隔は 1.5m 以下とし、これに照明器具を取付ける。
    また、必要に応じて振止めを設ける
  - 図「2種金属線ぴ及び照明器具の取付け」: 1.5m以下、金属管、つりボルト 呼び径 9mm 以上、2種金属線ぴ、ボックス、
    カバー、カバー止金物、照明器具
  - 図「2種金属線ぴの振止め」（p.397）: つりボルト、振止め、つり金物、2種金属線ぴ、照明器具
  - 2種金属線ぴと金属管等との間は、ボンディングを施し電気的に接続する
- 5.5 配線器具の取付け（p.397）
  - 配線器具の取付け位置は壁展開総合図で、他工事で設ける機器と納まりを調整する
  - 図（表題なし）: 柱、スイッチ、コンセント、1.3m、0.3m、0.2m（扉の横）、0.2m、0.15m、TV、コンセント、畳
- (5) には (1)〜(4) にあった「耐震支持」の項が無い
