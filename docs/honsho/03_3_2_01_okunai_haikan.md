## 表紙（p.345）

- 総合施工計画書の表紙（`03_2_2_sogo_rei.md`）と同じ構成で、表題だけが「屋内配管工事施工計画書」になる
  - 「工事名　○○○○○○新築電気設備工事」→ 表題 → 「工事監理　○○地方整備局　○○営繕事務所」「監理　○○設計事務所」
  - 押印欄: 受理・承諾（主任監督員、監督員）／確認（管理技術者、担当者）。「承諾は品質計画に係る部分」
  - 「受注者　○○○○電気工事株式会社」→ 押印欄: 現場代理人、監理技術者、工事担当者、工事担当者
- 総合の表紙との違い: 「管理技術者」に ※ が付かず、表の下の注記（※「管理技術者」は…）も無い

## 1. 一般事項（p.346）

- 1.1 総則
  - ① 適用範囲: この施工計画書は、○○○○○○新築電気設備工事の施工に適用する
  - ② 関係者への周知: この施工計画書は、工事着手前の打合せ等において関係者に周知徹底を図り、品質の確保に努める
  - ③ 適用図書及び参考図書: 総合施工計画書による

## 2. 工事管理（p.346）

- 2.1 施工内容
  - 建物内のコンクリート埋込み配管、天井・壁隠ぺい配管及び露出配管工事
- 2.2 工事計画
  - ① 施工図作成・提出・承諾時期: 施工図一覧表による。
    なお、施工図の提出に当たっては、施工図一覧表に提出日を記載して添付する
  - ② 施工時期: 週間工程表による。週間工程表は、定例打合せ会議で提出する
- 2.3 監督職員の施工の立会い時期
  - 金属管、PF管工事：コンクリート打設前／二重天井、壁仕上げ材取付け前

## 3. 現場の組織（p.346）

- 総合施工計画書による

## 4. 機材（p.346〜347）

- 4.1 使用機材
  - ① 機材及び製造者名（各行の右に「○○○○㈱製造」）

| 機材 | 内訳 |
|---|---|
| 合成樹脂製可とう電線管（PF管） | 同附属品（カップリング、コネクタ、コンビネーションカップリング）／エンドカバー／合成樹脂製ボックス、ボックスカバー |
| 鋼製電線管（ねじなし） | 同附属品（ノーマルベンド、ねじなしカップリング、コネクタ）／電線管用金属製ボックス、ボックスカバー |
| 金属製可とう電線管 | 同附属品（コネクタ、コンビネーションカップリング） |
| プルボックス | 鋼板製／合成樹脂製 |

  - ② 機材の識別方法: 製品及び包装の表示による
  - ③ 保管方法
    - 鋼製電線管は、資材置き場にまくら木を置いて保管し、ビニルシートで養生する
    - 合成樹脂製可とう電線管と金属製可とう電線管は、資材置き場の小屋内に保管する
- 4.2 機材の検査
  - 機材の搬入ごとに、受入確認（JISマーク等の確認、外観確認、数量確認）を行う
  - その後、監督職員に工事材料搬入報告書を提出し、検査を受ける

## 5. 施工要領（p.347〜。5.4 まで記録）

- 5.1 コンクリート埋込み配管（PF管）
  - ① 管の敷設
    - 配管は、PF管及び同附属品を使用する
    - ボックス付近を除き、平行する配筋及び配管相互の間隔は、30mm 以上とする
    - 梁に平行の配管は、梁面より 500mm 以上の間隔をあけて敷設する
    - 管の支持間隔は、バインド線（又は専用支持具）で 1m 以下とする
    - 図（p.348 上）: スラブ配筋内の PF 管敷設の姿図。図中の文字は次のとおり
      - 柱筋、コネクタ、コンクリート内アウトレットボックス、十分な支持結束、エンドカバー
      - 端末の保護やトロの侵入を防ぐためキャップ等を使用し、養生を行う。
      - 梁に沿っての配管は、梁面より 500mm 以上離して行う。
      - パイプ曲げ半径は管内径の6倍以上を原則とする。直角又はこれに近い屈曲は設けない。
      - 分電盤の上部・下部等で集中配管する場合は、建物強度を減少させないよう考慮のこと。たとえば、配管集中箇所は、
        その前でスラブ下に落とし込む等、配管ルートを変える。又、メッシュ等で、補強を行うか、あるいは
        スラブコンクリートを打増しする等の方法をとる。
      - 二重筋における交差は、踏みつけ圧縮を受けないよう上筋と下筋の重なり部分よりずらす。鉄筋に沿わせて配管しない。
    - 壁付でない梁の柱付近の横断配管は、次の図のとおり避ける
      - 図（p.348 下）: 梁断面（D：梁せい）と、柱まわりの平面図。柱から梁せい D の範囲を網掛けで示し、
        「壁付でない梁の横断配管を避ける部分（ただし、梁によって D は異なる。）」
  - ② 管及び合成樹脂ボックスの接続（p.349）
    - ボックスの使用区分は、次による

| 取付け位置 | 配管状況 | ボックスの種別 |
|---|---|---|
| 天井スラブ内 | (16)の配管5本以下又は(22)の配管3本以下 | 中形四角コンクリートボックス54又は八角コンクリートボックス75 |
| 天井スラブ内 | (16)の配管6本又は(22)の配管4本 | 大形四角コンクリートボックス54又は八角コンクリートボックス75 |
| 天井スラブ以外（床を含む。）スイッチ用位置ボックス | 連用スイッチ3個以下 | 1個用スイッチボックス又は中形四角アウトレットボックス44 |
| 同上 | 連用スイッチ6個以下 | 2個用スイッチボックス又は中形四角アウトレットボックス44 |
| 同上 | 連用スイッチ9個以下 | 3個用スイッチボックス |
| 天井スラブ以外（床を含む。）照明器具用、コンセント用位置ボックス等 | (16)の配管5本以下又は(22)の配管3本以下 | 中形四角アウトレットボックス44 |
| 同上 | (16)の配管6本又は(22)の配管4本 | 大形四角アウトレットボックス44 |
| 同上 | (28)の配管2本以下 | 大形四角アウトレットボックス54 |

    - 備考 連用スイッチには、連用形のパイロットランプ、接地端子、リモコンスイッチ等を含む
    - この表は「標仕」の表2.2.1（`02_3_hyo_1-2.md`）と同じ内容と見られる（未照合）
    - ボックスと管の接続は、コネクタを使用する
    - 管の接続は、カップリングを使用する
    - ボックスと管及び管相互の接続箇所は、0.3m 程度の位置に支持する
    - 図（p.349）: 下筋上のボックス・PF管・コネクタ・カップリング。支持位置はボックスから 0.3m 程度、
      支持間隔 1m 以下、カップリングの両側 0.3m 程度
  - ③ 養生（p.349）
    - 上向き配管は、端部に養生キャップを取付け、テープ巻きを行う
    - スラブ面から露出する屈曲部は、管立上げ支持鉄線（○○製）を用いる
- 5.2 天井内隠ぺい配管、軽量間仕切内配管（PF管）（p.350）
  - ① 管の敷設
    - 配管は PF管及び同附属品を使用する
    - 管は、PF管支持材（○○製）を用いて、1.5m 以下の間隔で支持する
    - ボックス付近は、0.3m 程度で支持する
    - ボックスとボックス間が 1m 程度の場合は、その中央の1点支持とする
    - 図（p.350）: つりボルト、PF管、支持材料、アウトレットボックス（金属製又は合成樹脂製）。
      配管支持間隔 L1：1m 程度は1点支持、L2：0.3m 程度、L3：1.5m 以下
  - ② 管及び合成樹脂ボックスの接続
    - 管及び合成樹脂ボックスの接続は、5.1②による
- 5.3 露出配管（鋼製電線管（ねじなし））（p.350〜351）
  - ① 管の敷設、プルボックスの取付け
    - 配管は鋼製電線管（ねじなし）及び同附属品を使用する
    - 管は、パイプハンガーにパイプクリップを用いて 2m 以下の間隔で支持する
    - パイプハンガーは、構造体につりボルト呼び径 9mm を取付け、これに固定する
    - ボックス付近は、0.5m 程度で支持する
    - 管の接続は、ねじなしカップリングを使用する
    - プルボックスは、構造体につりボルト呼び径 9mm を取付け、次の方法で固定する
      - 1) 支持は4箇所とするが、長辺が 300mm 以下は2箇所、200mm 以下は1箇所とする
      - 2) つりボルトに平座金とナットを用いて取付け、ねじ山を3つ程度残す
    - 図（p.351 上。単位 mm）: 側面図（つりボルト呼び径9mm以上、パイプクリップ、パイプハンガー、ボンド線）と
      平面図（電源側、負荷側、ボンド線、プルボックス、500以下、500以下、500以下、2,000以下）。
      標準図「プルボックス2 プルボックスと配管の支持例」（`docs/hyojunzu/README.md`、PDF p.152）とほぼ同じ図
    - ※使用するパイプクリップ、パイプハンガーの図が必要な場合は、製品に添付されている図（施工手順書等）を
      添付（コピー等の貼付）する
  - ② 管及びボックスの接続（p.351）
    - 露出配管の位置ボックス及びジョイントボックスの使用区分は、次による

| 用途 | 配管状況 | ボックスの種別 |
|---|---|---|
| 照明器具用等の位置ボックス及びジョイントボックス | (22)又は(E25)以下の配管4本以下 | 丸形露出ボックス（直径89mm） |
| 同上 | (28)又は(E31)以下の配管4本以下 | 丸形露出ボックス（直径100mm） |
| スイッチ用及びコンセント用位置ボックス | 連用スイッチ又は連用コンセント3個以下 | 露出1個用スイッチボックス |
| 同上 | 連用スイッチ又は連用コンセント6個以下 | 露出2個用スイッチボックス |
| 同上 | 連用スイッチ又は連用コンセント9個以下 | 露出3個用スイッチボックス |

    - 備考 連用スイッチ及び連用コンセントには、連用形のパイロットランプ、接地端子、リモコンスイッチ等を含む
    - 管とボックスとの接続は、ねじなしコネクタを使用する
    - 管とボックス間は、次の定格電流区分により絶縁電線（EM-IE）のボンディングを施す（5.3①の図を参照）

| 配線用遮断器等の定格電流 [A] | ボンド線の太さ |
|---|---|
| 30以下 | 1.6mm 以上 |
| 60以下 | 2.0mm 以上 |
| 100以下 | 5.5mm2 以上 |
| 225以下 | 14mm2 以上 |
| 600以下 | 38mm2 以上 |

- 5.4 露出配管（金属製可とう電線管）（p.352）
  - 管の敷設、ボックスとの接続
    - 配管は金属製可とう電線管及び同附属品を使用する
    - 使用する場所は、電動機への配線の保護管として使用する
    - 屋外及び水気のある場所では、ビニル被覆金属製可とう電線管を使用する
    - 鋼製電線管（ねじなし）との接続は、コンビネーションカップリング（ねじなし用）を使用する
    - 管の支持は、サドル、ハンガー等を使用し、その取付け間隔は、1m 以下とする。
      ただし、管相互、管とボックス等は、管端から 0.3m 以下の箇所で支持する
    - ボックスとの接続は、金属製可とう電線管に適合するコネクタ（可とう管用、ビニル被覆可とう管用）を使用する
    - 鋼製電線管（ねじなし）を支持する方法は、標準図「電力28」による
    - 図（p.352）: 冷却塔（電動機、ビニル被覆二種金属製可とう電線管、金属管、電線管支持金物（防錆処理）、
      アースクランプ、ボンド線、サドル止め、クリップによる支持）と、送風機（金属管、配管支持金物、端子箱、
      二種金属製可とう電線管）。標準図「電力28」は「配管類5 電動機への配線例」（PDF p.131）と推定。図柄は別物
