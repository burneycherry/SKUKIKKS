# 電気設備工事施工チェックシート（令和7年版）読み取り記録

- 出典: 「電気設備工事施工チェックシート 令和7年版」一般社団法人 公共建築協会 編集・発行（令和7年10月23日 第1刷）
- 目的: 既存の「品質管理チェックシート」（`data/checklist.js`）とは別に、本書のチェックシートを Excel 出力できるようにする
- ファイル名は `p＋開始ページ3桁_内容.md`（ページ順に並ぶ）。前付け・目次は `p000_maegaki.md`、本体は章ごと（`p001_ippan.md` 等）、参考資料は `p110_shinsei.md`
- 本書の表は「チェックポイント」（区分＋項目）と「記録」（空欄）の2列。記録欄は出力時に空欄で作る

## 記録の書式
- `## p.N 見出し（n/m）` … ページ。右上の柱（例「一般共通事項（1/8）」）を書く
- `### 区分名` … 左端の区分欄（例「契約時」）。前ページから続く場合も再掲する
- `- 1) 項目 〔1-1.1.1(2)〕` … 項目。〔 〕内は標準仕様書の項番号
- 丸囲みの「検」「立」は `[検]` `[立]` と書く
- 読み取りが曖昧な箇所は本文中に `【曖昧】` と書き、`00_kakunin.md` に管理番号（SC-nn）を付けて一覧化する

## アプリへの反映
- `python3 tools/build_sekocheck.py` で `data/sekocheck.js` を作る（記録を直したら再実行し、`sw.js` の `VERSION` を上げる）
- 原本から表記を変えたもの（`00_kakunin.md` の SC 番号）は変換ツールの `FIX_TEXT`・`fix_ref`・`parse_shinsei` に書く
- 「【曖昧】（…）」の注記と「（以下、空欄の行が…）」は出力しない。白紙・空白の記入用紙のページも出力しない
- 変換ツールは項目の無い区分を除いて警告する。出力後は `tools/check_sekocheck.py` で検査する
- 出力の仕様は `docs/shiyo/shorui.md`・`docs/shiyo/excel.md`
