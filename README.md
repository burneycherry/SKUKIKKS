# sekokan — 施工計画書メーカー（電気設備工事）

工事種目をチェックしていくだけで、施工計画書（管理表・品質計画）を Excel(xlsx) で出力する Web アプリ（PWA）です。
iOS の Safari / ホーム画面アプリを主対象とし、Android・PC のブラウザでも動作します。

## 使い方

1. `index.html` をブラウザで開く（GitHub Pages 等の https 配信ならホーム画面に追加してオフライン利用可）
2. 「工事情報」を入力
3. 「工事種目の選択」で該当する項目にチェック（「細目」を開くと細目単位で外せます）
4. 「Excel出力」を押す → ダウンロード、または「共有・ファイルに保存」

入力内容とチェック状態は端末内（localStorage）に保存され、サーバーには送信されません。

## 出力される Excel

| シート | 内容 |
|---|---|
| 表紙 | 書類名・工事名・工期・発注者・受注者など |
| 対象工事種目 | 選択した項目の一覧 |
| ⑴〜⑼ 各工事 | 管理表（選択した工事種目ごとに1シート） |
| 作成・提出資料一覧 | 管理表の作成資料をチェックリスト化 |
| 写真撮影項目一覧 | 管理表の写真欄をチェックリスト化 |

## データの出典

国土交通省「電気設備工事 施工管理 管理表（令和8年版）」（`source/` に原本 xlsx を格納）。
`python3 tools/build_data.py` で `data/kanrihyo.js` を再生成します（要 openpyxl）。
