# sekokan — 施工計画書メーカー（電気設備工事）

工事種目をチェックしていくだけで、施工計画書を Excel(xlsx) で出力する Web アプリ（PWA）です。
iOS の Safari / ホーム画面アプリを主対象とし、Android・PC のブラウザでも動作します。

## 作成できる書類

| 書類の種類 | 内容 |
|---|---|
| 総合 | 総合施工計画書（表紙・本文・工事概要・組織表・電気保安体制・品質管理体制・添付シート） |
| 工種別 | 工種別施工計画書（表紙・本文・管理表・対象工事種目・資料一覧・写真一覧）。16工種＋その他 |
| 施工計画書のみ | 簡略的な工事向けに、表紙・工事概要・組織表・管理表・各一覧を1冊にまとめる |
| チェックシート | 工種ごとの品質管理チェックシート（別ファイル） |
| 撮影箇所 | 工種ごとの工事写真の撮影箇所（別ファイル） |

このほか「出力内容」のチェックで、機器搬入計画書・ワイヤロープの選定・使用前自主検査の検査項目・
総合試運転のフローとチェックリスト・総合試運転報告書の表なども出力できます。

## 使い方

1. `index.html` をブラウザで開く（GitHub Pages 等の https 配信ならホーム画面に追加してオフライン利用可）
2. 「①工事情報」で書類の種類を選び、工事名などを入力
3. 「②工事種目の選択」で該当する項目にチェック（「細目」を開くと細目単位で外せます）
4. 「③出力内容」を確認して「Excel出力」を押す → ダウンロード、または「共有・ファイルに保存」

画面右上の「使い方」に、Excel 側で仕上げる部分（工事概要の設備概要、変更履歴など）をまとめています。
入力内容とチェック状態は端末内（localStorage）に保存され、サーバーには送信されません。

## フォルダ構成

| パス | 内容 |
|---|---|
| `index.html` / `css/` / `js/` | アプリ本体（`js/export/` が Excel 出力。書類ごとにファイルを分けている） |
| `data/` | 管理表・本文・チェックシート・撮影箇所のデータ |
| `vendor/` | ExcelJS（同梱。外部 CDN は使わない） |
| `sw.js` / `manifest.webmanifest` / `icons/` | PWA（オフライン用） |
| `tools/` | データ変換スクリプト・出力の回帰テスト |
| `source/` | 国交省 管理表（令和8年版）原本 xlsx |
| `docs/shiyo/` | アプリの詳細仕様 |
| `docs/honsho/` | 参考書籍の読み取り記録と確認事項 |
| `docs/hyojunzu/` | 国交省「標準図」PDF のページ索引 |

開発のルールは `CLAUDE.md` を参照してください。

## データの出典

- 国土交通省「電気設備工事 施工管理 管理表（令和8年版）」（`source/` に原本 xlsx を格納）。
  `python3 tools/build_data.py` で `data/kanrihyo.js` を再生成します（要 openpyxl）。
- 本文・チェックシート・撮影箇所は、書籍「電気設備工事の施工管理」の作成例をもとに作成（`docs/honsho/`）。
